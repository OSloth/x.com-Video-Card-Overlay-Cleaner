# x.com Video Card & Overlay Cleaner

專門清理 X (Twitter) 影片上的垃圾標籤。

很多推特上的推主或情色影片帳號，影片裡面跟下方都會帶有「來自 xxx」的浮動跳轉標籤或是 `t.me` 連結。車開到一半如果不小心誤點到，很容易直接被導向危險網頁或釣魚網站（甚至下載到怪怪的檔案導致電腦中毒）。

這個腳本會自動把這些浮動標籤跟外連全部幹掉，讓你安心看片不踩雷。

### 💡 功能細節
* 隱藏影片下方及影片內部「來自 / From」浮動標籤。
* 隱藏 `t.me` 等外部連結標籤。
* 支援頁面動態載入（往下滑動載入新影片時一樣會自動清理）。
