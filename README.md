# x.com Video Card & Overlay Cleaner

移除 X.com 影片下方、包含在影片內跳轉連結以及影片「來自 xxx」的浮動跳轉標籤容器。

## 安裝 (Installation)

點擊下方按鈕即可直接透過 Tampermonkey 安裝或更新：

[![Install with Tampermonkey](https://img.shields.io/badge/Install_with-Tampermonkey-00A88F?style=for-the-badge&logo=tampermonkey&logoColor=white)](https://raw.githubusercontent.com/OSloth/x.com-Video-Card-Overlay-Cleaner/main/x.com-cleaner.user.js?install)

---
> 💡 **小提示**：點擊後若跳出瀏覽器提示，請選擇允許透過 Tampermonkey 打開。
