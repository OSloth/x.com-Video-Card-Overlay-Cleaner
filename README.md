# x.com Video Card & Overlay Cleaner

專門清理 X (Twitter) 影片裡面跟下方那些很毒的垃圾連結。

很多車頭跟情色帳號很喜歡在影片裡嵌入「來自 xxx」標籤或 t.me 連結。

車開到一半誤點到，輕則跳廣告，重則直接進釣魚網站或下載病毒檔。

裝了這個自動把那些浮動標籤幹掉，還你一個乾淨的看片環境。

### 安裝連結

👉 **[點我到 Greasy Fork 安裝](https://greasyfork.org/zh-TW/scripts/589333-x-com-video-card-overlay-cleaner)**

---

### 💡 功能細節
* 隱藏影片下方及影片內部「來自 / From」浮動標籤。
* 隱藏 `t.me` 等外部連結標籤。
* 支援頁面動態載入（往下滑動載入新影片時一樣會自動清理）。
